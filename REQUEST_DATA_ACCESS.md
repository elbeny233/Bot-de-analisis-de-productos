# Borrador para solicitar acceso a datos — no enviado

Destinatario: canal oficial de atención o alianzas de la tienda elegida.
No se presume que exista API, feed, programa gratuito o autorización ya otorgada.

Asunto: Consulta sobre acceso autorizado a precios para Radar Ofertas VIP

Hola:

Estoy desarrollando Radar Ofertas VIP, un servicio de análisis de precios y descuentos.
Quisiera comenzar con un conjunto pequeño de productos para la ubicación de código
postal 37278. El proyecto contempla almacenar historial y compartir oportunidades,
con enlaces directos a su tienda, en una comunidad privada con acceso por suscripción.

Antes de integrar su tienda, deseo confirmar si permiten este uso y qué vía autorizada
recomiendan. Mi presupuesto inicial para APIs y licencias es de $0 MXN.

¿Podrían indicarme lo siguiente?

1. ¿Autorizan consultar precios automáticamente, guardar su historial y compartir los
   datos de ofertas para el propósito comercial descrito?
2. ¿Existe una API documentada, feed de productos, archivo de catálogo u otro medio
   autorizado gratuito que podamos utilizar? Si existe, ¿cuál es su documentación oficial?
3. ¿Se necesita una autorización por escrito, acuerdo o registro y cuáles son sus condiciones?
4. ¿Cómo se verifica el contexto de precios, disponibilidad y sucursal para CP 37278?
5. ¿Qué frecuencias, límites y datos pueden consultarse o almacenarse?
6. ¿Qué atribución, enlaces y restricciones deben respetarse al compartir las oportunidades?
7. ¿Hay restricciones específicas sobre imágenes, marcas, vendedores de Marketplace,
   promociones condicionadas y vigencia de precios?

No realizaremos compras automáticas, evitaremos datos personales y no utilizaremos
métodos para eludir CAPTCHA, bloqueos, autenticación o límites.

Gracias. Quedo atento a sus indicaciones y, de ser viable, a la autorización aplicable.

## Cuando llegue la respuesta

Conservar la respuesta y sus condiciones; compartir aquí su contenido sin credenciales
ni datos personales innecesarios. No enviar claves en el chat. Se verificará documentación,
licencia, contexto de ubicación y límites antes de escribir o activar el conector.
